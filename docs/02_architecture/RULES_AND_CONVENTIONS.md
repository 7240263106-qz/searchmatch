# 方湖观澜工程规则与约束

依据：2026-11-17 当前本地源码。本文件记录观察与本次文档工作约定，不表示项目负责人已经确认新的工程政策。

## 技术栈与组织

| 位置 | 职责 |
| --- | --- |
| `apps/web` | React、React Router、Vite、ECharts；页面与 UI |
| `apps/api` | NestJS、Prisma；HTTP、领域、业务与平台服务 |
| `apps/parser` | Python >=3.11、FastAPI；文件文本与结构解析 |
| `packages/contracts` | 共享类型、枚举、错误码和配置契约 |
| `scripts` / `deploy` | 配置门禁、数据维护、打包和部署；执行前辨别副作用 |

Node 声明 >=22.14.0、pnpm 声明 10.32.1。其他依赖范围见各应用清单；不把范围误写成已安装精确版本。

## 当前接口与业务约定

- API 前缀 `/api/v1`；普通成功响应以 `data` 为顶层，错误以 `error` 为顶层；文件与 CSV 为流响应。
- 发布状态与报名状态不同；学校认定、赛事级别、可信度不同。
- 个人文档、草稿、会话与团队资料必须依照对象归属授权；隐藏菜单不是安全控制。
- 字段修改保留依据、来源与版本；无法确认的内容保留缺失或待确认，不编造。
- 本次不统一重写编码格式，不修改现有业务实现和数据库。

## 当前命令

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | 启动 API/Web，解析器需另外启动 |
| `pnpm typecheck` | 工作区类型检查 |
| `pnpm --filter @competition/api test` | API 测试 |
| `pnpm build` | 运行环境门禁并依次构建 |
| `pnpm db:push` | 本地 schema 同步；不等于生产迁移 |
