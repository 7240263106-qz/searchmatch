## 现有事实

- React/Vite 前端 + NestJS API + FastAPI 解析器 + Prisma/SQLite。
- 四个一级工作区、13 个页面组件；配置中心包含七组页面。
- Prisma 当前定义 50 个模型；定义存在不代表业务闭环完成。
- 普通文档提取以规则为基础、模型可选；OCR 尚未形成实际调用链。
- 检索、角色/对象授权、任务恢复和已发布修订需要按设计收敛。
